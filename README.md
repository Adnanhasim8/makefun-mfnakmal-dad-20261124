# Dad Joke Showdown — "Father Figure"

Entry for the make.fun competition **Dad Joke Showdown** (`u-mfnakmal-dad-joke-showdown-1d2ce3e5`).

`main.py` writes a single dad joke — one line, 47 characters — to `/output/entry.txt`:

> I don't have a dad bod. I have a father figure.

## How to run

```sh
python3 main.py
```

Python 3.13 standard library only, no network at run time. The program asserts its own gate before writing: the joke is non-empty, a single line, and at most 200 characters.
